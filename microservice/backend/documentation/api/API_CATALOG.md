# Khandua Looms — Edge API Gateway & Microservices API Catalog

## 1. Edge API Gateway Routing

Spring Cloud Gateway acts as the unified reverse-proxy entry point on port **8090** (internal container port 8080).

### Standard Headers
- `Authorization: Bearer <jwt-token>` (Required on authenticated endpoints)
- `X-Correlation-ID: <uuid>` (Generated by Gateway if not provided; propagated downstream)

## 2. Service Endpoints Matrix

| :--- | :--- | :--- | :--- |

## 3. RFC 7807 Standardized Error Envelope

When any microservice encounters an error, it returns a uniform RFC 7807 `application/problem+json` response:
```json
{
  "type": "about:blank",
  "title": "Insufficient Stock",
  "status": 409,
  "detail": "Requested 2 items of product 3, but only 1 items are available",
  "instance": "/api/inventory/reserve",
  "timestamp": "2026-11-05T22:00:00Z"
}
```
